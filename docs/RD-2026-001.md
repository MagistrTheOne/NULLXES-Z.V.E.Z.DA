## 1. Recommendation

Build Z.V.E.Z.D.A as a 305.997B-total / 17.445B-active MoE production model on B300 multi-node, with research components present only as disabled configuration flags until their gates are passed.

This violates the conservative proxy-first route. The accepted mitigation is not to hide risk: baseline starts with GQA hybrid attention + MoE only; SSM interleave, L2 learned memory, latent recurrence, action-token behavior, and machine-state modality are off by default and require explicit gate activation.

### 3.1 Attention

Per layer GQA attention:

- Q projection: `d * d = 6144 * 6144 = 37,748,736`

- V projection: `d * d_kv = 6144 * 1024 = 6,291,456`

- Model attention total: `88,080,384 * 60 = 5,284,823,040`

### 3.2 Dense Prefix FFN

## 4. KV Cache

Per token per layer:

- K elements: `H_kv * d_head = 8 * 128 = 1024`
- V elements: `H_kv * d_head = 8 * 128 = 1024`
- KV elements per token/layer: `2048`

All layers:

- Elements per token all layers: `2048 * 60 = 122,880`
- Context elements per sequence at 32768: `122,880 * 32768 = 4,026,531,840`
- FP8 KV cache: `4,026,531,840 bytes = 3.75 GiB per sequence`
- BF16 KV cache: `8,053,063,680 bytes = 7.50 GiB per sequence`

Training memory is not derived from KV cache alone; activation checkpointing, sequence parallelism, context parallelism, microbatch, and recompute policy determine the real HBM envelope.

## 7. Baseline vs Research Bets

Baseline enabled at step 0:

- GQA causal attention.
- Hybrid 3:1 local/full schedule.
- Fine-grained MoE with normalized sigmoid routing, top-4 routed experts, one shared expert.
- Aux-loss-free expert bias update.
- MTP +1 auxiliary training head.
- FP8 Transformer Engine on B300.

Research bets disabled at step 0:

| Bet | Initial state | Gate to enable |
|---|---|---|
| Mamba-2 / SSM interleave | off | Throughput +15% at equal quality and no long-context regression |
| L2 learned memory | off | Long-horizon eval improvement over L1/L3 baseline with no perplexity regression >1% |
| Latent recurrent reasoning | off | Reasoning eval delta at equal train FLOPs against depth-equivalent baseline |
| Action-token space | off | Agentic environment success delta and no language-regression gate failure |
| Machine-state modality | off | Reproducible state-grounded eval gain, no training instability |

No disabled bet is allowed into the active production graph without a gate record in `experiments/`.

## 8. Data Plan

Hard constraints:

- Synthetic data never exceeds 35% of pretraining tokens.
- Every data source has license, hash, dedup status, tokenizer fertility, and quality-filter record.
- No mock data, placeholder shards, or synthetic “example corpus” are allowed in repo.

Initial pretraining mix:

| Segment | Share |
|---|---:|
| Filtered multilingual web | 45% |
| Code | 20% |
| STEM, math, papers, technical text | 15% |
| Russian high-quality web/books/docs | 12% |
| Verified synthetic and tool traces | 8% |

Data gates:

- Exact dedup plus MinHash near-dedup before tokenization.
- PII scrub before shard finalization.
- RU fertility ratio target: no worse than 1.20x English median on matched clean samples.
- Code fertility target: no worse than 1.15x tokenizer baseline on Python/JS/TS/Rust sample.
- Dataset version hash logged in every training run.

| Eval | Gate |
|---|---|

- No architectural baseline change through chat; only through gate record.

## 11. Stop Rules

Stop immediately and checkpoint state if any condition holds:

- Loss spike >2x running median sustained for 100 steps.
- Grad norm NaN/Inf or >10x stable baseline.
- MFU drop >20% sustained without infrastructure explanation.
- Tokens/s drop >20% sustained.
- One expert receives >40% tokens sustained after routing stabilization.
- More than 10% experts remain below 1% utilization after stabilization.
- Skipped MoE tokens exceed 5% sustained.
